ML Engineering from Scratch

Laboratoria sekcji A

Cztery osobne notebooki do pracy po wykładach. Przygotujesz działający notebook, własne obliczenia i pierwszą ocenę prognozy.

To wersja pilotażowa, gotowa do sprawdzenia przez uczestnika. Testy techniczne nie zastępują obserwacji początkującej osoby. Sekcje B–F mają na razie plan laboratoriów, bez gotowych notebooków.

Gdzie zacząć

Najpierw przeczytaj A1 i potrzebne lekcje A2. Ćwiczenia w wykładach wykonasz w przeglądarce. Po A3 uruchom lab-a00, następnie A01 i A02. A03 wykonaj po A4.1 i A4.2. Jeśli instalacja musi poczekać, zachowaj wyniki ćwiczeń przeglądarkowych; do lokalnych notebooków wróć, gdy środowisko będzie dostępne.

Pobierz własną kopię

Wybierz ZIP, aby pobrać notebook razem z instrukcją i potrzebnymi danymi. Rozpakuj zawarty w nim folder do ~/mle-practice/labs/. Nie nadpisuj dotychczasowej pracy. Pojedynczy plik notebooka przyda się do podglądu; w A03 potrzebuje również CSV z paczki.

README każdego labu podaje dokładne polecenie uruchomienia. W sekcji A wystarczą Python 3.12, JupyterLab i ipykernel przygotowane przez uv. Nie potrzebujesz bibliotek ML, konta GitHub ani GPU.
