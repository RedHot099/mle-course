    A2.2 · Ścieżka A–F

    Warunki, zero i brak obserwacji

    Pomiar równy zero mówi coś innego niż brak pomiaru. Napiszesz program, który rozpoznaje te sytuacje, i zobaczysz, jak warunki pozwalają wybrać właściwe działanie.

    • Przed lekcją: Wykonaj A2.1 lub upewnij się, że potrafisz używać liczb i zmiennych.
    • Jak pracować: przewiduj wyniki, uruchamiaj kod i wyjaśniaj to, co widzisz

    Wybierz jedną z dróg

    Czy towar jest dostępny? Możemy to sprawdzić warunkiem stock > 0. Wynik to True, jeśli stan magazynu jest większy od zera, lub False w przeciwnym razie.

    Instrukcja if pozwala wykonać kod tylko wtedy, gdy warunek jest prawdziwy. Pod else zapisujemy, co zrobić w pozostałych przypadkach.

    stock = 4
if stock > 0:
    print("available")
else:
    print("empty")

    Program wypisze available, bo stan wynosi 4. Dwukropek zapowiada blok kodu. Cztery spacje na początku linii pokazują, które polecenia do niego należą. Co wypisze ten sam program po zmianie stanu na zero?

    Który zapis pyta o równość?

    • stock == 0Podwójny znak równości porównuje wartości.
    • stock = 0Pojedynczy znak przypisuje nową wartość.
    • stock + 0To dodawanie, a nie pytanie.

    != oznacza "różne", >= "większe lub równe", a < "mniejsze". Za pomocą elif możesz sprawdzić kolejny warunek. Python sprawdza je od góry i wykonuje tylko pierwszy pasujący blok:

    value = -2
if value < 0:
    print("invalid")
elif value == 0:
    print("zero")
else:
    print("positive")

    Oddziel brak od zera

    W naszych przykładach None oznacza brak pomiaru. Sprzedaż równa 0 to znany wynik: w danym dniu nic się nie sprzedało. Wartość None mówi natomiast, że nie wiemy, ile się sprzedało.

    Co wypisze ten kod?

    value = 0
if value is None:
    print("missing")
else:
    print("known")
    • knownZero jest znaną wartością, więc nie jest None.
    • missingWarunek is None pyta o brak, nie o zerową sprzedaż.

    Brak pomiaru sprawdzaj warunkiem is None, a jego obecność warunkiem is not None. Skrót if value: nie rozróżnia tych sytuacji: zarówno dla zera, jak i dla None warunek jest fałszywy. Jeśli użyjesz go do wybierania pomiarów, możesz przez przypadek pominąć zera.

    has_stock = 4 > 0
is_open = True
print(has_stock and is_open)

    Operator and łączy dwa warunki. Wynik jest prawdziwy tylko wtedy, gdy oba są prawdziwe. Ten kod wyświetli True. Zmień is_open na False i przewidź wynik.

    Nadaj obserwacji status

    Znana liczba

    Uzupełnij kod tak, żeby w zmiennej status znalazł się napis "missing", gdy value jest równe None. Dla liczby zapisz "known". Zero również jest znaną wartością.

    Sprawdź swój kod dla trzech przypadków: zera, None i liczby 5. Po każdej zmianie value uruchom sprawdzenie ponownie.

    Podpowiedź 1

    Sprawdź dokładnie brak wartości, nie to, czy liczba jest dodatnia.

    Podpowiedź 2

    Zarówno pod if, jak i pod else przypisz odpowiedni napis do status.

    Sprawdź, co pamiętasz

    Czy brak obserwacji oznacza zero? Dlaczego używasz == zamiast = w porównaniu?

    Sprawdź własne wyjaśnienie

    Zero jest znanym wynikiem pomiaru, a brak oznacza, że wyniku nie mamy. Znak = przypisuje wartość. Operator == porównuje dwie wartości. Wyjaśnij każdą z tych różnic na własnym przykładzie.
