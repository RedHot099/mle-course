    A2.5 · Ścieżka A–F

    Pierwsza własna funkcja

    Znasz już kilka obliczeń, które można wykonać na liście. Teraz zapiszesz takie obliczenie jako własną funkcję, żeby używać go z różnymi danymi. Sprawdzisz też, dlaczego wyświetlenie wyniku i zwrócenie go to dwie różne rzeczy.

    • Przed lekcją: A2.1–A2.4.
    • Jak pracować: przewiduj wyniki, uruchamiaj kod i wyjaśniaj to, co widzisz

    Nadaj operacji nazwę

    Funkcja pozwala nadać nazwę fragmentowi kodu i wykonać go wtedy, gdy jest potrzebny. Po def zapisujesz nazwę funkcji i jej parametry. Parametr jest nazwą, pod którą funkcja otrzyma dane przy wywołaniu.

    W przykładzie poniżej number to parametr. Wywołanie triple(2) przekazuje mu wartość 2. Polecenie return kończy obliczenie i zwraca wynik, który można zapisać w zmiennej.

    def triple(number):
    return number * 3

first = triple(2)
second = triple(5)
print(first, second)

    Program wypisze 6 15. Samo def definiuje funkcję. Obliczenie zaczyna się przy triple(2): parametr number otrzymuje 2, a zwrócone 6 trafia do first. Drugie wywołanie wykonuje ten sam kod z wartością 5.

    Co wypisze ostatnia linia?

    def show_double(number):
    print(number * 2)

result = show_double(3)
print(result)
    • NoneFunkcja wyświetla 6, ale nie zwraca tej liczby. Bez return jej wynikiem jest None.
    • 6To wypisze sama funkcja, ale zmienna result otrzyma None.

    Przekaż inne dane

    Do funkcji możesz przekazać również listę. Poniższa funkcja zwraca ostatni element podanej listy. Jeśli lista jest pusta, zwraca None, ponieważ nie ma elementu do odczytania:

    def last_value(values):
    if len(values) == 0:
        return None
    return values[-1]

print(last_value([2, 7]))
print(last_value([]))

    Program wypisze 7 i None. W pustej liście nie ma ostatniego elementu, więc pierwszy return kończy wywołanie wcześniej. Zwróć uwagę na położenie tego polecenia. Jeśli umieścisz return wewnątrz pętli, może zakończyć funkcję przed sprawdzeniem pozostałych elementów.

    Napisz funkcję od początku

    Liczba znanych obserwacji

    Uzupełnij funkcję count_known(values). Ma policzyć, ile elementów listy jest różnych od None, i zwrócić tę liczbę. Zero również się liczy.

    Funkcja powinna działać także dla pustej listy i pozostawiać przekazaną listę bez zmian. Nazwa i parametr są już gotowe. Twój kod wpisz w ciele funkcji.

    Podpowiedź 1

    Zastanów się, kiedy zacząć liczenie, co robić dla każdego elementu i kiedy zwrócić końcowy wynik.

    Podpowiedź 2

    Utwórz licznik przed pętlą. W pętli rozpoznawaj elementy inne niż None. Zwróć wynik dopiero po sprawdzeniu całej listy.

    Sprawdź, co pamiętasz

    Czy print i return robią to samo? Dlaczego licznik powstaje przed pętlą?

    Sprawdź własne wyjaśnienie

    print wyświetla wartość, a return pozwala zapisać ją w zmiennej lub użyć w innym obliczeniu. Licznik utworzony przed pętlą zachowuje sumę z poprzednich kroków. Gdyby licznik zerował się w każdym kroku, wcześniejszy wynik by przepadał.
