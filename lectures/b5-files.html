    B5.2 · Ścieżka A–F

    Odczytaj i zapisz mały plik

    Pomiary nie zawsze są wpisane bezpośrednio w kodzie. Odczytasz je z małego pliku, a raport zapiszesz w drugim. Jeśli Python nie znajdzie pliku, będziesz wiedzieć, jak sprawdzić, gdzie go szuka.

    • Przed lekcją: B5.1. Przykłady na stronie działają bez instalacji. Do pracy z plikami na komputerze przygotuj środowisko z A3.
    • Jak pracować: przewiduj wyniki, uruchamiaj kod i wyjaśniaj to, co widzisz

    Ustal, gdzie szukasz pliku

    Gdy podajesz samą nazwę readings.txt, Python szuka pliku w swoim bieżącym folderze, nazywanym katalogiem roboczym. Taki zapis to ścieżka względna.

    Pełny adres, na przykład /home/anna/mle-practice/readings.txt, to ścieżka bezwzględna. Wskazuje miejsce w systemie plików niezależnie od katalogu roboczego. Uważaj: terminal i notebook nie muszą pracować w tym samym folderze.

    Moduł pathlib jest częścią Pythona i służy do pracy ze ścieżkami. Instrukcja from pathlib import Path udostępnia nazwę Path w Twoim kodzie. Utworzony obiekt opisuje ścieżkę, a po kropce wywołujesz jego metody:

    from pathlib import Path

print(Path.cwd())
path = Path("lesson_readings.txt")
print(path.name)

    Program najpierw wyświetli katalog roboczy, a potem nazwę lesson_readings.txt. Jeśli dostaniesz komunikat o braku pliku, sprawdź wynik Path.cwd(). Czy jest to folder, w którym znajduje się Twój plik?

    Zamknij plik także przy błędzie

    Poniższy przykład najpierw tworzy plik z trzema liniami, a potem go odczytuje. Zapis \n oznacza koniec linii w napisie. Parametr encoding="utf-8" określa sposób zapisu i odczytu znaków:

    from pathlib import Path

path = Path("lesson_readings.txt")
path.write_text("8\n?\n0\n", encoding="utf-8")
with path.open(encoding="utf-8") as handle:
    for line in handle:
        print(line.strip())

    Program wypisze 8, ? i 0. Blok with zamknie plik także wtedy, gdy w jego środku wystąpi błąd. Metoda strip() usuwa białe znaki z końców tekstu, na przykład znak końca linii. Wynik nadal jest napisem. Dopiero float("8") zamienia go na liczbę 8.0.

    Plik w przeglądarce

    Pliki tworzone przez kod na stronie istnieją wewnątrz interpretera w przeglądarce. Nie trafiają do folderu Downloads i możesz je utracić po odświeżeniu strony. Aby zachować własne pliki, wykonaj kod w notebooku na swoim komputerze.

    Zachowaj zero, oznacz brak

    Każda linia jest napisem, także gdy wygląda jak liczba.

    Po usunięciu znaku końca linii sprawdź, czy został znak ?. Dopiero tekst z liczbą przekaż do float.

    Przenieś wynik na dysk

    W notebooku z A3 utwórz my_readings.txt z co najmniej czterema własnymi pomiarami. Odczytaj plik tym samym kodem po zmianie ścieżki. Następnie zapisz krótki raport do my_report.txt za pomocą write_text. Otwórz oba pliki i sprawdź, czy wejście pozostało bez zmian.

    Metoda write_text zapisuje tekst. Liczbę możesz wcześniej zamienić na napis przez str, na przykład str(total), jeśli suma jest już policzona. Jeśli raport ma kilka nazwanych pól, możesz użyć formatu JSON:

    import json
from pathlib import Path

report = {"status": "ready", "rows": 4}
text = json.dumps(report, ensure_ascii=False)
Path("lesson_report.json").write_text(text, encoding="utf-8")

    Przykład zapisuje pola status i rows do pliku JSON. Otwórz plik i znajdź obie wartości. Podobnie sprawdź później własny raport: samo zakończenie programu bez błędu nie mówi jeszcze, co zostało zapisane.

    Dodatek: pobieraj wartości z generatora

    Ten dodatek możesz przeczytać po wykonaniu zadania z odczytem. Generator pozwala pobierać wartości po jednej, zamiast od razu budować całą listę. Polecenie yield oddaje jedną wartość i wstrzymuje funkcję do kolejnego pobrania:

    def labels(names):
    for name in names:
        yield "item: " + name

items = labels(["red", "blue"])
print(list(items))
print(list(items))

    Pierwsze list(items) pobierze obie etykiety. Drugie zwróci pustą listę, bo z tego generatora pobrano już wszystkie wartości. Aby zacząć ponownie, trzeba jeszcze raz wywołać labels.

    Przechodzenie po kolejnych elementach nazywamy iteracją; pojedynczy krok to jedna iteracja pętli. Otwarty plik też pozwala pobierać kolejne linie. Dlatego pętla może zacząć odczyt, zanim cały plik znajdzie się w pamięci. Plik jest iteratorem, choć nie jest funkcją z yield.

    Przed B6 i B7 wystarczy opanować odczyt pliku z głównej części lekcji. Do generatora możesz wrócić później. Wtedy wyjaśnij, dlaczego utworzenie generatora i pobranie jego elementów to dwie różne czynności.

    Sprawdź, co pamiętasz

    Dlaczego Python może zgłosić FileNotFoundError, mimo że nazwa pliku jest poprawna?

    Sprawdź własne wyjaśnienie

    Sama nazwa pliku nie wystarczy, jeśli Python szuka w innym folderze. Sprawdź Path.cwd() i porównaj ścieżkę z miejscem zapisania pliku. Rozwiąż ten problem przed rozpoczęciem obliczeń.
