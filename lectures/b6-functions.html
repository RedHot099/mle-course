    B6.1 · Ścieżka A–F

    Napisz funkcję o jasno opisanym działaniu

    Napiszesz funkcję, która oblicza średnią znanych pomiarów. Najpierw ustalisz, co ma zwracać i co zrobić, gdy nie ma ani jednego pomiaru. Ten opis będzie podstawą kodu i późniejszych testów.

    • Przed lekcją: A2.5 oraz B5.1–B5.3.
    • Jak pracować: przewiduj wyniki, uruchamiaj kod i wyjaśniaj to, co widzisz

    Zacznij od opisu działania

    Pierwsza linia definicji podaje nazwę i parametry funkcji. Nazywamy ją sygnaturą. Pod nią możesz umieścić docstring, czyli opis w potrójnym cudzysłowie.

    Dobry opis odpowiada na pytania: jakie dane przekazać, jaki wynik otrzymamy i kiedy wystąpi błąd. To właśnie mamy na myśli, mówiąc o umowie funkcji. Kod i testy powinny być zgodne z tym opisem.

    def label_count(name, count=0):
    """Return a label for a non-negative count.

    Raises:
        ValueError: The count is negative.
    """
    if count < 0:
        raise ValueError("count must be non-negative")
    return name + ": " + str(count)

print(label_count("rows"))
print(label_count("rows", count=3))

    Program wypisze rows: 0 i rows: 3. Gdy pomijasz count, funkcja używa domyślnego zera. W drugim wywołaniu zapis count=3 przekazuje argument po nazwie. Nie tworzy zmiennej count poza funkcją.

    Oddziel obliczenie od wypisywania

    Funkcja może obliczyć wynik i zwrócić go przez return. Nie musi od razu go wyświetlać ani zapisywać w pliku. To kod, który ją wywołuje, zdecyduje, co zrobić z wynikiem.

    Taki podział ułatwia testowanie. Możesz przekazać kilka małych list i za każdym razem porównać zwróconą wartość z własnym rachunkiem.

    Co wypisze ostatnia linia?

    value = 9

def increase(value):
    value = value + 1
    return value

increase(value)
print(value)
    • 9value wewnątrz funkcji jest lokalnym parametrem. Przypisanie go nie zmienia zewnętrznej nazwy.
    • 10Funkcja zwraca 10, ale poza nią nie przypisujemy wyniku do value. Ta zmienna zachowuje poprzednią wartość.

    Przypisanie wewnątrz funkcji zmienia jej lokalną zmienną value. Nie zmienia zmiennej o tej samej nazwie poza funkcją. Inaczej działa append: zmienia samą listę, co widzieliśmy w B5.1.

    Funkcję, która oblicza wynik tylko z przekazanych argumentów i nie zmienia danych ani niczego poza sobą, nazywamy czystą. W zadaniu poniżej funkcja ma tylko liczyć średnią. Odczyt i zapis plików pozostaw poza nią.

    Wypróbuj funkcję na innych danych

    Bez zaglądania do kodu oblicz ręcznie wynik dla [None, 0, 8, 4], a potem wywołaj swoją funkcję. Własnymi słowami wyjaśnij, dlaczego [] nie powinno zwracać zera.

    Sprawdź uzasadnienie

    Wyjaśnij różnicę między wynikiem równym zero a brakiem danych do obliczenia wyniku. Zero może być średnią istniejących pomiarów. Dla pustej listy nie ma pomiarów, które można uśrednić. Porównaj też ręczny rachunek z wynikiem swojej funkcji.

    Sprawdź, co pamiętasz

    Co kończy wykonanie funkcji? Jak przekazujesz obliczony wynik do innego fragmentu programu?

    Sprawdź własne wyjaśnienie

    return kończy wywołanie i zwraca wynik. print wyświetla informację na ekranie. Jeśli nadal mylisz te czynności, wróć do przykładu w A2.5 i sprawdź wartość zmiennej result.
