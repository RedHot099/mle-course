    Sprawdź, od czego zacząć

    Uruchomisz pierwszy kod i wybierzesz potrzebne lekcje podstaw. Diagnoza nie jest egzaminem. Nie musisz znać odpowiedzi, żeby zacząć kurs.

    • Przed lekcją: Przeglądarka z dostępem do sieci. Bez instalowania Pythona, konta GitHub i tutora.

    Najpierw uruchom kod

    Naciśnij Uruchom. Pierwsze uruchomienie pobiera interpreter Python do przeglądarki. Gdy zobaczysz napis poniżej, miejsce do pracy jest gotowe.

    Oczekiwany wynik to Mogę zacząć. Zmień napis między cudzysłowami i uruchom ponownie. To pole jest Twoim edytorem. Przycisk wykonuje wpisany kod.

    Gdy runner nie działa

    Jeśli pojawia się błąd pobrania Pythona, sprawdź połączenie i spróbuj ponownie. To problem środowiska, nie Twojej wiedzy. Treść można czytać, a pytania rozwiązywać na papierze; wykonywanie kodu wróci w A3.

    Przewidź, potem sprawdź

    Najpierw odpowiedz bez uruchamiania. Przy błędzie przeczytaj wyjaśnienie. Jeśli temat jest nieznany, zapisz wskazaną lekcję. Wynik quizów nie blokuje nawigacji.

    Co wypisze program?

    count = 4
count = count + 3
print(count)
    • 4Drugie przypisanie zastępuje poprzednią wartość.
    • BłądDodawanie liczb i ponowne przypisanie są poprawne.
    • 7Przypisanie oblicza prawą stronę, więc 4 + 3 daje 7.

    Która wartość oznacza brak obserwacji?

    • 0Zero może oznaczać obserwację bez sprzedaży. To nie brak pomiaru.
    • FalseFalse to wynik logiczny, a nie standardowy zapis brakującej liczby.
    • NoneNone oznacza brak wartości; zero jest znaną liczbą.

    Co pozostaje w total?

    total = 0
for value in [2, 0, 6]:
    total = total + value
print(total)
    • 6Ostatnia wartość nie zastępuje sumy. Każdy krok ją powiększa.
    • 3Trzy to liczba elementów, nie ich suma.
    • 8Pętla dodaje kolejno 2, 0 i 6.

    Co wypisze program?

    row = {"product": "plum", "sale": 0}
print(row["sale"])
    • plumTo wartość pod kluczem product.
    • saleWyrażenie w nawiasach wybiera wartość pod wskazanym kluczem.
    • 0Klucz sale wskazuje zero, które jest prawidłową obserwacją.

    Co wypisze ostatnia linia?

    def double(value):
    return value * 2

result = double(4)
print(result)
    • 8return oddaje wynik wywołującemu. Ten wynik trafia do result.
    • 4Funkcja mnoży argument przez dwa.
    • NoneBez return wynikiem byłoby None, ale tutaj return jest.
