    Sprawdź, od czego zacząć

    Nie musisz niczego instalować ani znać Pythona, żeby zacząć. Najpierw uruchomisz krótki program na tej stronie. Potem kilka pytań pomoże Ci wybrać lekcje, od których warto zacząć naukę.

    • Przed lekcją: Wystarczy przeglądarka z internetem. Nie potrzebujesz konta GitHub ani zainstalowanego Pythona.
    • Jak pracować: przewiduj wyniki, uruchamiaj kod i wyjaśniaj to, co widzisz

    Najpierw uruchom kod

    Naciśnij Uruchom pod kodem. Za pierwszym razem trzeba chwilę poczekać: przeglądarka pobiera interpreter, czyli program, który wykonuje polecenia Pythona.

    Pod kodem zobaczysz napis Mogę zacząć. Zmień tekst w cudzysłowach i naciśnij Uruchom ponownie. W tym samym polu możesz później sprawdzać przykłady z lekcji, które nie mają własnego przycisku uruchamiania.

    Jeśli kod się nie uruchamia

    Jeśli pobieranie interpretera się nie udało, sprawdź połączenie i ponów próbę. W międzyczasie możesz rozwiązać pytania na papierze. W A3 uruchomisz Pythona także na swoim komputerze.

    Przewidź, potem sprawdź

    Spróbuj przewidzieć wynik każdego programu, zanim go uruchomisz. Błędna odpowiedź jest wskazówką, co warto powtórzyć. Przeczytaj wyjaśnienie i zanotuj temat, który sprawił Ci trudność. Wynik quizu nie blokuje dostępu do żadnej lekcji.

    Co wypisze program?

    count = 4
count = count + 3
print(count)
    • 4Drugie przypisanie zastępuje poprzednią wartość.
    • BłądDodawanie liczb i ponowne przypisanie są poprawne.
    • 7Przypisanie oblicza prawą stronę, więc 4 + 3 daje 7.

    Która wartość oznacza brak obserwacji?

    • 0Zero może oznaczać obserwację bez sprzedaży. To nie brak pomiaru.
    • FalseFalse to wynik logiczny, a nie standardowy zapis brakującej liczby.
    • NoneNone oznacza brak wartości; zero jest znaną liczbą.

    Jaką wartość będzie mieć total po wykonaniu pętli?

    total = 0
for value in [2, 0, 6]:
    total = total + value
print(total)
    • 6Ostatnia wartość nie zastępuje sumy. Każdy krok ją powiększa.
    • 3Trzy to liczba elementów, nie ich suma.
    • 8Pętla dodaje kolejno 2, 0 i 6.

    Co wypisze program?

    row = {"product": "plum", "sale": 0}
print(row["sale"])
    • plumTo wartość pod kluczem product.
    • saleWyrażenie w nawiasach wybiera wartość pod wskazanym kluczem.
    • 0Klucz sale wskazuje zero, które jest prawidłową obserwacją.

    Co wypisze ostatnia linia?

    def double(value):
    return value * 2

result = double(4)
print(result)
    • 8return zwraca wynik, który w tym przykładzie zapisujemy w result.
    • 4Funkcja mnoży argument przez dwa.
    • NoneBez return wynikiem byłoby None, ale tutaj return jest.
