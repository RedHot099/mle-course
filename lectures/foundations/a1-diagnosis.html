    Sprawdź, od czego zacząć

    Uruchom pierwszy program w przeglądarce. Potem sprawdź, które podstawy już znasz, a do których warto wrócić. Możesz zacząć bez żadnego doświadczenia z Pythonem.

    • Przed lekcją: Przeglądarka z dostępem do sieci. Bez instalowania Pythona, konta GitHub i tutora.
    • Tryb: najpierw przewidź, potem wykonaj i wyjaśnij

    Najpierw uruchom kod

    Naciśnij Uruchom pod kodem. Przy pierwszej próbie przeglądarka pobierze interpreter, czyli program wykonujący kod Python. Poczekaj na wynik pod polem.

    Pod polem powinien pojawić się napis Mogę zacząć. Zmień tekst w cudzysłowach i uruchom kod jeszcze raz. Możesz tu też wklejać przykłady z kolejnych lekcji, jeśli nie mają własnego przycisku uruchamiania.

    Gdy runner nie działa

    Jeśli pobieranie interpretera się nie udało, sprawdź połączenie i ponów próbę. W międzyczasie możesz rozwiązać pytania na papierze. W A3 uruchomisz Python także na swoim komputerze.

    Przewidź, potem sprawdź

    Wybierz odpowiedź, zanim uruchomisz kod. Jeśli się pomylisz, przeczytaj wyjaśnienie i zapisz temat do powtórki. Możesz przejść do dowolnej lekcji, niezależnie od wyniku quizów.

    Co wypisze program?

    count = 4
count = count + 3
print(count)
    • 4Drugie przypisanie zastępuje poprzednią wartość.
    • BłądDodawanie liczb i ponowne przypisanie są poprawne.
    • 7Przypisanie oblicza prawą stronę, więc 4 + 3 daje 7.

    Która wartość oznacza brak obserwacji?

    • 0Zero może oznaczać obserwację bez sprzedaży. To nie brak pomiaru.
    • FalseFalse to wynik logiczny, a nie standardowy zapis brakującej liczby.
    • NoneNone oznacza brak wartości; zero jest znaną liczbą.

    Co pozostaje w total?

    total = 0
for value in [2, 0, 6]:
    total = total + value
print(total)
    • 6Ostatnia wartość nie zastępuje sumy. Każdy krok ją powiększa.
    • 3Trzy to liczba elementów, nie ich suma.
    • 8Pętla dodaje kolejno 2, 0 i 6.

    Co wypisze program?

    row = {"product": "plum", "sale": 0}
print(row["sale"])
    • plumTo wartość pod kluczem product.
    • saleWyrażenie w nawiasach wybiera wartość pod wskazanym kluczem.
    • 0Klucz sale wskazuje zero, które jest prawidłową obserwacją.

    Co wypisze ostatnia linia?

    def double(value):
    return value * 2

result = double(4)
print(result)
    • 8return oddaje wynik wywołującemu. Ten wynik trafia do result.
    • 4Funkcja mnoży argument przez dwa.
    • NoneBez return wynikiem byłoby None, ale tutaj return jest.
