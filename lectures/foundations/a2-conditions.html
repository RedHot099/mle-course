    Warunki, zero i brak obserwacji

    Napisz program, który rozpoznaje brak obserwacji. Sprawdzisz, dlaczego zero i brak wymagają różnych odpowiedzi.

    • Przed lekcją: A2.1 albo samodzielna praca z liczbą i nazwą.
    • Tryb: najpierw przewidź, potem wykonaj i wyjaśnij

    Wybierz jedną z dróg

    Porównanie stock > 0 ma wynik True, gdy stan jest dodatni, albo False w pozostałych przypadkach. Po if podajesz taki warunek. Python wykona blok pod nim, jeśli warunek jest prawdziwy. W przeciwnym razie wykona blok pod else.

    stock = 4
if stock > 0:
    print("available")
else:
    print("empty")

    Program wypisze available, bo stan wynosi 4. Dwukropek zapowiada blok kodu. Cztery spacje na początku linii pokazują, które polecenia do niego należą. Co wypisze ten sam program po zmianie stanu na zero?

    Który zapis pyta o równość?

    • stock == 0Podwójny znak równości porównuje wartości.
    • stock = 0Pojedynczy znak przypisuje nową wartość.
    • stock + 0To dodawanie, a nie pytanie.

    != oznacza "różne", >= "większe lub równe", a < "mniejsze". Za pomocą elif możesz sprawdzić kolejny warunek. Python sprawdza je od góry i wykonuje tylko pierwszy pasujący blok:

    value = -2
if value < 0:
    print("invalid")
elif value == 0:
    print("zero")
else:
    print("positive")

    Oddziel brak od zera

    None oznacza brak wartości. Zapis 0 mówi, że zmierzona sprzedaż wyniosła zero. Zapis None mówi, że nie znamy wyniku pomiaru. Te obserwacje niosą inną informację.

    Co wypisze ten kod?

    value = 0
if value is None:
    print("missing")
else:
    print("known")
    • knownZero jest znaną wartością, więc nie jest None.
    • missingWarunek is None pyta o brak, nie o zerową sprzedaż.

    O brak pytaj przez is None, a o znaną wartość przez is not None. Sam warunek if value: uzna zarówno None, jak i zero za fałsz. Przez taki skrót możesz przypadkiem usunąć zera z obliczeń.

    Znana liczba

    Przypisz do status napis "missing", gdy value jest None. Dla liczby, także zera, przypisz "known". Po pierwszej próbie zmień value na None, a potem na 5. Sprawdź każdą z tych trzech sytuacji.

    Powrót bez zaglądania

    Czy brak obserwacji oznacza zero? Dlaczego używasz == zamiast = w porównaniu?

    Sprawdź własne wyjaśnienie

    Zero jest znanym wynikiem pomiaru, a brak oznacza, że wyniku nie mamy. Znak = przypisuje wartość. Operator == porównuje dwie wartości. Wyjaśnij każdą z tych różnic na własnym przykładzie.
