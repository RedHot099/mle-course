    Warunki, zero i brak obserwacji

    Wybierzesz działanie zależnie od danych i zachowasz różnicę między zerem a brakiem.

    • Przed lekcją: A2.1 albo samodzielna praca z liczbą i nazwą.
    • Tryb: najpierw przewidź, potem wykonaj i wyjaśnij

    Wybierz jedną z dróg

    Porównanie, takie jak stock > 0, daje wartość logiczną: True albo False. if wykonuje wcięty blok, gdy warunek jest prawdziwy. else wybiera drugą drogę.

    stock = 4
if stock > 0:
    print("available")
else:
    print("empty")

    Wynik to available. Dwukropek zaczyna blok. Wcięcie czterech spacji oznacza, co do niego należy. Zmień w myślach stock na zero. Wybierzesz wtedy drugą drogę.

    Który zapis pyta o równość?

    • stock == 0Podwójny znak równości porównuje wartości.
    • stock = 0Pojedynczy znak przypisuje nową wartość.
    • stock + 0To dodawanie, a nie pytanie.

    != oznacza różne, >= większe lub równe, < mniejsze. elif pozwala dodać kolejny warunek. Sprawdzamy warunki od góry i wykonujemy pierwszy pasujący blok.

    value = -2
if value < 0:
    print("invalid")
elif value == 0:
    print("zero")
else:
    print("positive")

    Oddziel brak od zera

    None oznacza brak wartości. Jeśli pomiar sprzedaży wynosi zero, wiemy, że odnotowano zero. Jeśli wynosi None, nie znamy liczby. Nie wolno ich utożsamiać.

    Co wypisze ten kod?

    value = 0
if value is None:
    print("missing")
else:
    print("known")
    • knownZero jest znaną wartością, więc nie jest None.
    • missingWarunek is None pyta o brak, nie o zerową sprzedaż.

    Do sprawdzania braku używaj is None lub is not None. Zapis if value: pomija także zero. Dlatego w danych liczbowych potrzebujesz precyzyjnego pytania.

    Nadaj obserwacji status

    Znana liczba

    Uzupełnij warunek tak, aby status wynosił "missing" dla None i "known" dla każdej liczby, także zera. Po sprawdzeniu zmień value ręcznie na None oraz 5 i uruchom ponownie.

    Podpowiedź 1

    Sprawdź dokładnie brak wartości, nie to, czy liczba jest dodatnia.

    Podpowiedź 2

    Obie drogi powinny przypisać napis do nazwy status.

    Powrót bez zaglądania

    Czy brak obserwacji oznacza zero? Dlaczego używasz == zamiast = w porównaniu?

    Sprawdź własne wyjaśnienie

    Brak nie daje informacji o liczbie. Zero ją daje. Znak = przypisuje; == porównuje. Zmień value na None, a potem na dodatnią liczbę i sprawdź własny warunek.
