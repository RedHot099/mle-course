    Pierwsza własna funkcja

    Oddasz wynik obliczenia wywołującemu i użyjesz tej samej funkcji na innych danych.

    • Przed lekcją: A2.1–A2.4.
    • Tryb: najpierw przewidź, potem wykonaj i wyjaśnij

    Nadaj operacji nazwę

    Funkcja pozwala nazwać operację. def rozpoczyna definicję. Parametr to nazwa danych otrzymanych przy wywołaniu. return oddaje wynik i kończy to wywołanie.

    def triple(number):
    return number * 3

first = triple(2)
second = triple(5)
print(first, second)

    Wynik to 6 15. Definicja nie uruchamia obliczenia. Robi to wywołanie, na przykład triple(2). Nazwa number otrzymuje wtedy wartość 2.

    Co wypisze ostatnia linia?

    def show_double(number):
    print(number * 2)

result = show_double(3)
print(result)
    • NoneFunkcja tylko wypisuje 6. Bez return oddaje None.
    • 6To wypisze sama funkcja, ale zmienna result otrzyma None.

    Przekaż inne dane

    Funkcja może otrzymać listę. Zmienne utworzone w jej wnętrzu są lokalne dla wywołania. Kolejne wywołanie zaczyna obliczenie od nowa.

    def last_value(values):
    if len(values) == 0:
        return None
    return values[-1]

print(last_value([2, 7]))
print(last_value([]))

    Wyniki to 7 i None. Funkcja ma dwie drogi oddania wyniku: dla pustej i niepustej listy. W funkcji z pętlą uważaj na return wewnątrz pętli, bo zakończy wywołanie już przy pierwszym wykonaniu tej linii.

    Napisz funkcję od początku

    Liczba znanych obserwacji

    Napisz count_known(values). Wynik to liczba elementów innych niż None. Funkcja ma działać także dla pustej listy i nie może zmieniać listy wejściowej. Podpis i pusty środek są już przygotowane.

    Podpowiedź 1

    Początek, przejście po danych i oddanie wyniku to trzy różne momenty.

    Podpowiedź 2

    Zacznij licznik przed pętlą. W pętli sprawdzaj tylko None. Return potrzebny jest po pętli.

    Powrót bez zaglądania

    Czy print i return robią to samo? Dlaczego count powstaje przed pętlą?

    Sprawdź własne wyjaśnienie

    Print pokazuje komunikat. Return udostępnia wynik innemu kodowi. Licznik powstaje przed pętlą, żeby nie zerować go przy każdym elemencie. Jeśli nie umiesz samodzielnie napisać podobnej funkcji, powtórz lekcję przed przejściem do B.
