    A2.3 · Ścieżka A–F

    Listy i pętle krok po kroku

    Gdy pomiarów jest kilka, nie trzeba pisać osobnego polecenia dla każdego z nich. Zapiszesz je w liście, a potem użyjesz pętli, żeby policzyć ich sumę i liczbę znanych wartości.

    • Przed lekcją: A2.1 i A2.2.
    • Jak pracować: przewiduj wyniki, uruchamiaj kod i wyjaśniaj to, co widzisz

    Przechowaj kolejne obserwacje

    Lista przechowuje elementy w określonej kolejności. Tworzysz ją za pomocą nawiasów kwadratowych. Pozycję elementu wskazuje indeks, a liczbę elementów podaje len. Indeksy zaczynają się od zera:

    values = [3, 0, 5]
print(values[0])
print(values[2])
print(len(values))

    Program wypisze 3, 5 i 3. Zapis values[-1] wybiera ostatni element. Wycinek values[:2] wybiera elementy przed indeksem 2, czyli dwa pierwsze. Z kolei values[2:] wybiera elementy od indeksu 2 do końca:

    print([3, 0, 5, 8][:2])
print([3, 0, 5, 8][2:])

    Otrzymasz [3, 0] i [5, 8]. Taki podział przyda się do oddzielenia historii od przyszłości.

    Prześledź każdą iterację

    Zapis for value in values rozpoczyna pętlę po liście. W pierwszym kroku zmienna value przyjmuje pierwszy element, w drugim drugi i tak dalej. Za każdym razem Python wykonuje kod zapisany z wcięciem pod pętlą. Jeden taki krok nazywamy iteracją.

    Jaki jest wynik?

    total = 0
for value in [2, 5, 0]:
    total = total + value
print(total)
    • 3To liczba elementów, nie suma.
    • 7Suma rośnie kolejno z 0 do 2, 7 i 7.
    • 0Zero na końcu jest dodawane, a nie przypisywane zamiast sumy.

    W powyższym kodzie print stoi za pętlą, więc wypisuje końcową sumę tylko raz. Możesz też zbudować nową listę. Zacznij od [] i dodawaj do niej elementy przez append. To metoda listy, czyli operacja wywoływana po kropce:

    doubled = []
for value in [1, 4]:
    doubled.append(value * 2)
print(doubled)

    Wynikiem jest lista [2, 8]. Jeśli lista jest pusta, nie można wybrać z niej ostatniego elementu. Można jednak przejść po niej pętlą: kod wewnątrz pętli nie wykona się wtedy ani razu.

    Policz znane wartości

    Zero też się liczy

    Na liście są pomiary oraz wartości None, oznaczające brak pomiaru. Policz znane wartości i zapisz ich liczbę w known_count. W zmiennej total zapisz ich sumę.

    Uwzględnij zera, bo są poprawnymi pomiarami. Użyj pętli i zmiennych z przykładu, żeby program działał również po zmianie listy.

    Podpowiedź 1

    Zastanów się, które elementy chcesz pominąć. Czy zero jest jednym z nich?

    Podpowiedź 2

    Licznik i sumę aktualizuj wewnątrz warunku value is not None.

    Sprawdź, co pamiętasz

    Co da pętla po pustej liście? Jak wybierzesz pierwsze trzy elementy?

    Sprawdź własne wyjaśnienie

    Dla pustej listy blok pętli nie wykona się ani razu. Wycinek [:3] zawiera elementy o indeksach 0, 1 i 2. Uruchom też swój kod dla [] oraz [0, None] i wyjaśnij wyniki.
