    A2.3 · Ścieżka A i B

    Listy i pętle krok po kroku

    Policzysz sumę i liczbę znanych obserwacji bez gubienia zer.

    • Przed lekcją: A2.1 i A2.2.
    • Tryb: najpierw przewidź, potem wykonaj i wyjaśnij

    Przechowaj kolejne obserwacje

    Lista trzyma elementy w kolejności. Nawiasy kwadratowe tworzą listę. Indeks zaczyna się od zera, a len daje jej długość.

    values = [3, 0, 5]
print(values[0])
print(values[2])
print(len(values))

    Wyniki to 3, 5 i 3. Ostatni element można też wybrać przez values[-1]. Przez values[:2] wybierasz pierwsze dwa elementy. Zapis przed dwukropkiem to początek, za nim koniec bez tego elementu.

    print([3, 0, 5, 8][:2])
print([3, 0, 5, 8][2:])

    Otrzymasz [3, 0] i [5, 8]. Taki podział przyda się do oddzielenia historii od przyszłości.

    Prześledź każdą iterację

    for value in values przypisuje kolejne elementy do nazwy value. Każde przejście to iteracja. Wcięty blok wykonuje się dla każdego elementu.

    Jaki jest wynik?

    total = 0
for value in [2, 5, 0]:
    total = total + value
print(total)
    • 3To liczba elementów, nie suma.
    • 7Suma rośnie kolejno z 0 do 2, 7 i 7.
    • 0Zero na końcu jest dodawane, a nie przypisywane zamiast sumy.

    Po ostatniej iteracji pętla się kończy. Linia bez wcięcia jest wykonywana raz. Aby budować nową listę, zacznij od [] i użyj append. To metoda listy: po kropce piszesz jej nazwę, a w nawiasach nowy element.

    doubled = []
for value in [1, 4]:
    doubled.append(value * 2)
print(doubled)

    Wynik to [2, 8]. Pusta lista nie ma ostatniego elementu, ale pętla po niej jest poprawna i wykonuje zero iteracji.

    Policz znane wartości

    Zero też się liczy

    Dla podanej listy policz known_count i total, pomijając tylko None. Użyj pętli. Nie wpisuj samej oczekiwanej liczby, bo dane będą się zmieniać w dalszych ćwiczeniach.
