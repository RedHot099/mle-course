    A3 · Ścieżka A–F

    Przenieś pracę do notebooka

    Dotąd kod działał na stronie kursu. Teraz uruchomisz go na swoim komputerze i zapiszesz w notebooku. Zobaczysz też, dlaczego zapisany plik i zmienne w pamięci programu to nie to samo.

    • Przed lekcją: Podstawy Pythona z A2. Jeśli już je znasz, wystarczą ćwiczenia sprawdzające z A1.
    • Jak pracować: przewiduj wyniki, uruchamiaj kod i wyjaśniaj to, co widzisz

    Terminal, edytor i kernel

    MiejsceCo tam wpisujeszPrzykład
    Terminal systemuPolecenia uruchamiające programyuv --version
    Komórka notebookaKod Pythonprint(2 + 3)
    Edytor pliku .pyKod, który zapisujesz przed uruchomieniemprint("ready")

    Notebook pozwala wykonywać kod w osobnych komórkach. Wykonuje go kernel, czyli uruchomiony w tle Python. Kernel pamięta utworzone zmienne tak długo, jak działa.

    Plik notebooka przechowuje kod i zapisane wyniki widoczne na ekranie. Nie przechowuje jednak działającego Pythona ani jego zmiennych. Po restarcie kernela trzeba wykonać kod ponownie.

    Dwa środowiska

    To różnica względem pól kodu na stronie kursu, gdzie każde uruchomienie zaczyna się bez zmiennych z poprzedniej próby. W notebooku komórki korzystają ze wspólnej pamięci kernela. Wynik może więc zależeć od komórki wykonanej wcześniej, nawet jeśli później ją zmienisz lub usuniesz.

    Przygotuj terminal

    Na Linuxie otwórz terminal. Na Windowsie korzystamy z Ubuntu w WSL2. Jeśli masz już WSL2, otwórz terminal Ubuntu. Jeśli nie, przejdź przez instalację WSL2 z lekcji 00 i wróć tutaj. Na tym etapie pomiń sterownik NVIDIA.

    Jeśli instalacja wymaga pomocy właściciela komputera, możesz najpierw wykonać ćwiczenia przeglądarkowe. Do notebooka i plików lokalnych wrócisz, gdy środowisko będzie dostępne.

    Wpisz w terminalu poniższe polecenie, żeby sprawdzić, czy masz już uv:

    uv --version

    Jeśli widzisz numer wersji, uv jest gotowe. Jeśli terminal nie rozpoznaje polecenia, zainstaluj uv. Poniższe polecenie pochodzi z oficjalnej instrukcji uv i jest przeznaczone dla terminala Linux lub Ubuntu w WSL:

    curl --retry 5 --retry-all-errors -LsSf https://astral.sh/uv/install.sh | sh

    Zamknij i otwórz terminal. Ponownie sprawdź uv --version. Nie wpisuj powyższych poleceń do komórki Python.

    Utwórz osobne miejsce do nauki

    Utwórz folder mle-practice w swoim katalogu domowym. mkdir -p tworzy folder, cd przechodzi do niego, a pwd pokazuje bieżącą ścieżkę. Ostatnie polecenie uruchomi prosty rachunek w Pythonie:

    mkdir -p ~/mle-practice
cd ~/mle-practice
pwd
uv run --no-project --python 3.12 python -c "print(2 + 3)"

    Jeśli wszystko działa, zobaczysz wynik 5. Opcja --python 3.12 wybiera wersję Pythona. Jeśli nie ma jej na komputerze, uv ją pobierze. Opcja --no-project pozwala uruchomić ten przykład bez instalowania bibliotek całego kursu.

    Uruchom i zapisz notebook

    Z tego samego terminala uruchom:

    uv run --no-project --python 3.12 --with jupyterlab --with ipykernel jupyter lab

    Uv przygotuje środowisko z JupyterLab i wypisze adres strony działającej na Twoim komputerze. Otwórz ten adres w przeglądarce i zostaw terminal uruchomiony. Jeśli używasz WSL, otwórz adres w przeglądarce Windows.

    1. W JupyterLab wybierz nowy notebook z kernelem Python 3.
    2. Nazwij plik first_steps.ipynb.
    3. W pierwszej komórce wpisz stock = 6 i uruchom ją przez Shift+Enter.
    4. W drugiej wpisz print(stock + 2). Oczekiwany wynik to 8.
    5. Zapisz notebook przez Ctrl+S.
    6. W menu Kernel wybierz Restart Kernel and Run All Cells. Nazwa może nieznacznie różnić się między wersjami. Ponownie powinieneś zobaczyć 8.

    Otwórz drugi notebook i uruchom w nim print(stock), bez wcześniejszego przypisania. Zobaczysz NameError. Nowy notebook ma własny kernel, w którym nazwa stock jeszcze nie istnieje.

    Zakończenie pracy

    Po zakończeniu wybierz Kernel → Shut Down Kernel, aby zatrzymać Python wykonujący notebook. Następnie wróć do terminala Jupyter, naciśnij Ctrl+C i potwierdź zatrzymanie serwera.

    Sprawdź zapis i ponowne uruchomienie

    Zamknij notebook i otwórz go ponownie. Zrestartuj kernel, a potem wykonaj wszystkie komórki od początku. Czy otrzymujesz ten sam wynik, czyli 8?

    Dodaj komórkę tekstową. Zapisz w niej, gdzie znajduje się plik notebooka i dlaczego przed obliczeniem potrzebna jest linia stock = 6.

    Gdzie wpiszesz uv --version?

    • W terminaluTo polecenie uruchamiające program uv.
    • W komórce PythonZwykła komórka oczekuje składni Python, a nie polecenia terminala.

    Jeśli Jupyter nie startuje, zachowaj polecenie i komunikat błędu. Pomiń token dostępu z wypisanego adresu. Do ćwiczeń Python możesz tymczasowo wrócić w przeglądarce. Jeśli Jupyter działa, ale kod zwraca zły wynik, sprawdź najpierw dane i kolejność wykonania komórek.
