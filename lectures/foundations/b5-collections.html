    Kolekcje i zmiany danych

    Dobierzesz kolekcję do pytania i zbudujesz wynik bez zmiany danych wejściowych.

    • Przed lekcją: A2 i A4. Możesz pracować w przeglądarce.
    • Tryb: najpierw przewidź, potem wykonaj i wyjaśnij

    Wybierz kolekcję do pytania

    Znasz już listę i słownik. Lista zachowuje kolejność obserwacji. Słownik pozwala wybierać wartość po nazwanym kluczu. Dwie kolejne kolekcje to tuple i set.

    PotrzebaKolekcjaPrzykład
    Wartości w kolejności dnilist[3, 0, 5]
    Pola rekordudict{"day": "Mon", "sale": 3}
    Stała paratuple("north", 12)
    Unikalne identyfikatoryset{"north", "south"}

    Tuple nie pozwala zastąpić własnego elementu przypisaniem. Set usuwa powtórzenia i nie daje kolejności dni. in pyta o obecność elementu. Funkcja sorted tworzy uporządkowaną listę, jeśli jej potrzebujesz.

    cities = ["north", "south", "north"]
unique = set(cities)
print(len(unique))
print("north" in unique)
print(sorted(unique))

    Wynik to 2, True i lista north, south. Nie stosuj set do historii sprzedaży: usunąłby powtarzające się obserwacje, które mogą dotyczyć różnych dni.

    Przypisanie nie robi kopii

    Co zobaczysz?

    original = [3, 5]
other = original
other.append(8)
print(original)
    • [3, 5, 8]Obie nazwy wskazują tę samą listę.
    • [3, 5]Nowej listy nie utworzono. Przypisanie nie kopiuje.

    Listę można zmienić, więc jest mutowalna. list(original) tworzy nową listę. To wystarcza dla listy liczb. Przy listach zawierających kolejne listy elementy wewnętrzne nadal mogą być współdzielone; wrócimy do tego w obecnym module 01.

    Funkcja otrzymująca listę też nie dostaje automatycznej kopii. Zanim zaczniesz dopisywać lub usuwać elementy, ustal, czy zmiana wejścia jest częścią umowy. W naszych zadaniach wynik ma powstawać osobno.

    Od pętli do comprehension

    doubled = []
for value in [1, 3, 4]:
    doubled.append(value * 2)
print(doubled)

    Gdy rozumiesz pętlę, tę samą nową listę możesz zapisać krócej:

    doubled = [value * 2 for value in [1, 3, 4]]
print(doubled)

    Obie wersje dają [2, 6, 8]. Ten zapis to comprehension. Pętla jest nadal poprawnym wyborem, szczególnie gdy łatwiej ją prześledzić. Filtrowanie przez comprehension poznasz później; teraz przećwicz wybór elementów zwykłą pętlą. Nie musisz skracać kodu, którego jeszcze nie rozumiesz.

    Zachowaj wejście

    Nowa lista znanych wartości

    Napisz without_missing(values). Zwróć nową listę bez None, w pierwotnej kolejności, pozostawiając zera i powtórzenia. Użyj zwykłej pętli i warunku.

    Podpowiedź 1

    Nie usuwaj elementów w trakcie przechodzenia po tej samej liście.

    Podpowiedź 2

    Buduj nową listę i dodawaj tylko wartości inne niż None.

    Powrót bez zaglądania

    Dlaczego set nie nadaje się do historii? Co może zmienić append wykonane przez inną nazwę?

    Sprawdź własne wyjaśnienie

    Set gubi powtórzenia i kolejność. Append zmienia obiekt listy, więc zmianę widać przez każdą nazwę tej listy. Wróć do quizu o przypisaniu, jeśli oczekiwałeś kopii.
