    Odczytaj i zapisz mały plik

    Odczytaj pomiary z małego pliku i zapisz raport w innym pliku. Sprawdzisz przy tym, w którym folderze Python szuka danych.

    • Przed lekcją: B5.1. Pliki lokalne wymagają A3; doświadczenia w runnerze działają bez instalacji.
    • Tryb: najpierw przewidź, potem wykonaj i wyjaśnij

    Ustal, gdzie szukasz pliku

    Ścieżka readings.txt oznacza plik w bieżącym katalogu programu. To ścieżka względna. Ścieżka bezwzględna, na przykład /home/anna/mle-practice/readings.txt, wskazuje miejsce od korzenia systemu plików. Notebook i terminal mogą mieć różne katalogi robocze.

    Moduł pathlib jest częścią Pythona i służy do pracy ze ścieżkami. Instrukcja from pathlib import Path udostępnia nazwę Path w Twoim kodzie. Utworzony obiekt opisuje ścieżkę, a po kropce wywołujesz jego metody:

    from pathlib import Path

print(Path.cwd())
path = Path("lesson_readings.txt")
print(path.name)

    Pierwsza linia pokaże katalog roboczy, a druga nazwę lesson_readings.txt. Jeśli program nie znajduje pliku, porównaj wynik Path.cwd() z folderem, w którym plik zapisałeś.

    Zamknij plik także przy błędzie

    Poniższy przykład najpierw tworzy plik z trzema liniami, a potem go odczytuje. Zapis \n oznacza koniec linii w napisie. Parametr encoding="utf-8" określa sposób zapisu i odczytu znaków:

    from pathlib import Path

path = Path("lesson_readings.txt")
path.write_text("8\n?\n0\n", encoding="utf-8")
with path.open(encoding="utf-8") as handle:
    for line in handle:
        print(line.strip())

    Program wypisze 8, ? i 0. Blok with zamknie plik także wtedy, gdy w jego środku wystąpi błąd. Metoda strip() usuwa białe znaki z końców tekstu, na przykład znak końca linii. Wynik nadal jest napisem. Dopiero float("8") zamienia go na liczbę 8.0.

    Plik w przeglądarce

    Przenieś wynik na dysk

    W notebooku z A3 utwórz my_readings.txt z co najmniej czterema własnymi pomiarami. Odczytaj plik tym samym kodem po zmianie ścieżki. Następnie zapisz krótki raport do my_report.txt za pomocą write_text. Otwórz oba pliki i sprawdź, czy wejście pozostało bez zmian.

    Metoda write_text zapisuje tekst. Liczbę możesz wcześniej zamienić na napis przez str, na przykład str(total), jeśli obliczyłeś już sumę. Jeśli raport ma kilka nazwanych pól, możesz użyć formatu JSON:

    import json
from pathlib import Path

report = {"status": "ready", "rows": 4}
text = json.dumps(report, ensure_ascii=False)
Path("lesson_report.json").write_text(text, encoding="utf-8")

    Przykład zapisuje pola status i rows do pliku JSON. Otwórz plik i znajdź obie wartości. Podobnie sprawdź później własny raport: samo zakończenie programu bez błędu nie mówi jeszcze, co zostało zapisane.

    Dodatek: pobieraj wartości z generatora

    Ten dodatek możesz przeczytać po wykonaniu zadania z odczytem. Generator pozwala pobierać wartości po jednej, zamiast od razu budować całą listę. Polecenie yield oddaje jedną wartość i wstrzymuje funkcję do kolejnego pobrania:

    def labels(names):
    for name in names:
        yield "item: " + name

items = labels(["red", "blue"])
print(list(items))
print(list(items))

    Pierwsze list(items) pobierze obie etykiety. Drugie zwróci pustą listę, bo z tego generatora pobrano już wszystkie wartości. Aby zacząć ponownie, trzeba jeszcze raz wywołać labels.

    Pobieranie elementów po jednym nazywamy iteracją. Otwarty plik też pozwala pobierać kolejne linie. Dlatego pętla może zacząć odczyt, zanim cały plik znajdzie się w pamięci. Plik jest iteratorem, choć nie jest funkcją z yield.

    Przed B6 i B7 wystarczy opanować odczyt pliku z głównej części lekcji. Do generatora możesz wrócić później. Wtedy wyjaśnij, dlaczego utworzenie generatora i pobranie jego elementów to dwie różne czynności.

    Powrót bez zaglądania

    Dlaczego poprawna nazwa pliku może kończyć się FileNotFoundError?

    Sprawdź własne wyjaśnienie

    Sprawdź Path.cwd() i ścieżkę do pliku. Poprawna nazwa nie wystarczy, jeśli Python szuka jej w innym folderze. Brakujący plik wymaga wyjaśnienia, zanim rozpoczniesz obliczenia.
