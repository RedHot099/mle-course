    Odczytaj i zapisz mały plik

    Odczytasz tekst linia po linii, rozpoznasz katalog roboczy i zapiszesz osobny wynik.

    • Przed lekcją: B5.1. Pliki lokalne wymagają A3; doświadczenia w runnerze działają bez instalacji.
    • Tryb: najpierw przewidź, potem wykonaj i wyjaśnij

    Ustal, gdzie szukasz pliku

    Ścieżka względna, taka jak readings.txt, jest liczona od bieżącego katalogu programu. Notebook i terminal mogą mieć inny katalog. Ścieżka bezwzględna zaczyna się od korzenia systemu plików.

    pathlib to moduł standardowej biblioteki Python. Import udostępnia potrzebne nazwy. Nie musisz instalować pathlib. Path opisuje ścieżkę; po kropce wybierasz jego metodę.

    from pathlib import Path

print(Path.cwd())
path = Path("lesson_readings.txt")
print(path.name)

    Pierwsza linia wyniku to katalog roboczy. Druga to nazwa lesson_readings.txt. Jeśli czytasz nie ten plik, zacznij diagnozę od katalogu, nie od zmieniania danych.

    Zamknij plik także przy błędzie

    Doświadczenie tworzy mały plik demonstracyjny, a następnie go czyta. \n w napisie oznacza nową linię. UTF-8 to jawne kodowanie znaków.

    from pathlib import Path

path = Path("lesson_readings.txt")
path.write_text("8\n?\n0\n", encoding="utf-8")
with path.open(encoding="utf-8") as handle:
    for line in handle:
        print(line.strip())

    Zobaczysz 8, ?, 0. Blok with pilnuje zamknięcia pliku. strip() zwraca tekst bez białych znaków na początku i końcu. Nie zmienia napisu w liczbę. float("8") zwraca 8.0.

    Plik w przeglądarce

    W runnerze plik znajduje się w wirtualnym systemie plików interpretera w przeglądarce. Nie pojawi się w Twoim folderze Downloads. Odświeżenie może go usunąć. Do zachowania pracy kopiuj kod i uruchom go w lokalnym notebooku.

    Przygotowanie pliku jest dostarczone. W values odczytaj liczby typu float. Znak ? zamień na None. Użyj with, pętli oraz strip. Nie zmieniaj treści pliku.

    Każda linia jest napisem, także gdy wygląda jak liczba.

    Podpowiedź 2

    Najpierw usuń znak końca linii. Przed float sprawdź znak braku.

    Przenieś wynik na dysk

    W notebooku z A3 utwórz plik o innej nazwie, na przykład my_readings.txt, z co najmniej czterema własnymi pomiarami. Odczytaj go tym samym sposobem. Zapisz krótki raport do nowego pliku my_report.txt przez write_text. Nie nadpisuj wejścia.

    Możesz zapisać znaną wartość przez zamianę jej na napis: str(total). Gdy wynik ma zawierać wiele pól, przyda się JSON:

    import json
from pathlib import Path

report = {"status": "ready", "rows": 4}
text = json.dumps(report, ensure_ascii=False)
Path("lesson_report.json").write_text(text, encoding="utf-8")

    To gotowy przykład formatu, nie zadanie do uzupełnienia. W pliku zobaczysz nazwy pól i ich wartości. Zanim uznasz własny zapis za poprawny, otwórz utworzony plik i przeczytaj jego treść.

    Dodatek po działającym odczycie: generator

    W tym dodatku wynik nie musi od razu być całą listą. Generator oddaje wartości po jednej, na żądanie. Zamiast return jednej gotowej kolekcji używa yield dla kolejnych wartości.

    def labels(names):
    for name in names:
        yield "item: " + name

items = labels(["red", "blue"])
print(list(items))
print(list(items))

    Pierwsze list(items) zbiera dwie etykiety. Drugie daje pustą listę, bo generator został zużyty. Nowe wywołanie labels tworzy nowy generator. To wyjaśnia też, dlaczego czytanie pliku po jednej linii nie wymaga zebrania wszystkich linii w pamięci przed pierwszym obliczeniem. Obiekt otwartego pliku jest iteratorem, choć nie jest funkcją generatorową.

    Dodatek nie blokuje B6 ani B7. Zanim użyjesz generatora w większym zadaniu, wyjaśnij różnicę między utworzeniem generatora a pobraniem jego elementów.
