    B6.1 · Ścieżka A i B

    Funkcja ma wejście, wynik i umowę

    Zaprojektujesz małą funkcję, która zwraca wynik i jawnie odrzuca przypadek bez poprawnej odpowiedzi.

    • Przed lekcją: A2.5 oraz B5.1–B5.3.
    • Tryb: najpierw przewidź, potem wykonaj i wyjaśnij

    Opisz zachowanie przed środkiem funkcji

    Sygnatura to nazwa i parametry funkcji. Docstring to napis zaraz pod def. Opisuje jej umowę: co przyjmuje, co zwraca i kiedy zgłasza błąd. W tym kursie czytaj docstring przed pisaniem środka.

    def label_count(name, count=0):
    """Return a label for a non-negative count.

    Raises:
        ValueError: The count is negative.
    """
    if count < 0:
        raise ValueError("count must be non-negative")
    return name + ": " + str(count)

print(label_count("rows"))
print(label_count("rows", count=3))

    Wyniki to rows: 0 i rows: 3. Domyślny argument jest używany, gdy go pominiesz. W drugim wywołaniu podajesz argument po nazwie. To opis wywołania, nie tworzenie nowej zmiennej poza funkcją.

    Oddziel obliczenie od wypisywania

    Funkcja obliczeniowa nie musi pytać o dane ani wypisywać raportu. Wynik oddaje przez return. Inny kod decyduje, czy go pokazać, zapisać czy porównać z oczekiwaniem. Ułatwia to sprawdzanie na małych wejściach.

    Co wypisze ostatnia linia?

    value = 9

def increase(value):
    value = value + 1
    return value

increase(value)
print(value)
    • 9value wewnątrz funkcji jest lokalnym parametrem. Przypisanie go nie zmienia zewnętrznej nazwy.
    • 10Funkcja oddaje 10, ale wywołujący nie przypisuje tego wyniku do swojej nazwy value.

    Przy liście sytuacja jest inna: append zmienia sam obiekt, co widziałeś w B5.1. Funkcja czysta oblicza wynik z argumentów i nie zmienia wejścia ani plików. Odczyt i zapis pliku trzymamy oddzielnie od liczenia.

    Średnia znanych wartości

    Jawnie odrzuć brak odpowiedzi

    Napisz mean_known(values). Przyjmuje listę liczb nieujemnych i None. Zwraca float: średnią znanych wartości, zachowując zera. Dla [] oraz samych None zgłasza ValueError z tekstem "no known values". Nie zmienia listy wejściowej. Nie musisz jeszcze walidować innych typów ani liczb ujemnych.

    Podpowiedź 1

    Najpierw ustal, ile jest znanych wartości i jaka jest ich suma.

    Podpowiedź 2

    Przed dzieleniem sprawdź, czy istnieje mianownik różny od zera. Wynik oddaj po całej pętli.

    Sprawdź na własnym wejściu

    Bez zaglądania do kodu oblicz ręcznie wynik dla [None, 0, 8, 4], a potem wywołaj swoją funkcję. Własnymi słowami wyjaśnij, dlaczego [] nie powinno zwracać zera.

    Sprawdź uzasadnienie

    Wymagana jest różnica między średnią równą zero a brakiem danych do średniej. W pierwszym przypadku obserwacje istnieją. W drugim nie ma wartości, po których można uśredniać. Ręczny wynik nowego wejścia porównaj z kodem, zamiast ufać samemu zielonemu sprawdzeniu.

    Powrót bez zaglądania

    Gdzie funkcja kończy wywołanie? Czy rezultat ma być wypisany, czy zwrócony?

    Sprawdź własne wyjaśnienie

    Return kończy wywołanie i oddaje wartość. Print jest osobnym efektem ubocznym. Wróć do A2.5, jeśli mylisz widoczny tekst z wynikiem funkcji.
