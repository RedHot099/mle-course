    B6.1 · Ścieżka A i B

    Funkcja ma wejście, wynik i umowę

    Napisz funkcję liczącą średnią znanych pomiarów. Opisz jej wynik i zachowanie wtedy, gdy nie ma z czego policzyć średniej.

    • Przed lekcją: A2.5 oraz B5.1–B5.3.
    • Tryb: najpierw przewidź, potem wykonaj i wyjaśnij

    Przeczytaj umowę funkcji

    Sygnatura podaje nazwę i parametry funkcji. Docstring to opis umieszczony zaraz pod def. Określa, co funkcja przyjmuje, co zwraca i kiedy zgłasza błąd. Ten opis jest umową, według której piszesz kod i sprawdzasz wynik.

    def label_count(name, count=0):
    """Return a label for a non-negative count.

    Raises:
        ValueError: The count is negative.
    """
    if count < 0:
        raise ValueError("count must be non-negative")
    return name + ": " + str(count)

print(label_count("rows"))
print(label_count("rows", count=3))

    Program wypisze rows: 0 i rows: 3. Gdy pomijasz count, funkcja używa domyślnego zera. W drugim wywołaniu zapis count=3 przekazuje argument po nazwie. Nie tworzy zmiennej count poza funkcją.

    Oddziel obliczenie od wypisywania

    Funkcja może zwrócić wynik przez return, a kod poza nią zdecyduje, co z nim zrobić: wyświetlić, zapisać lub porównać z oczekiwaniem. Dzięki temu tę samą funkcję łatwo sprawdzisz na kilku małych wejściach.

    Co wypisze ostatnia linia?

    value = 9

def increase(value):
    value = value + 1
    return value

increase(value)
print(value)
    • 9value wewnątrz funkcji jest lokalnym parametrem. Przypisanie go nie zmienia zewnętrznej nazwy.
    • 10Funkcja oddaje 10, ale wywołujący nie przypisuje tego wyniku do swojej nazwy value.

    W przykładzie przypisanie zmienia lokalną nazwę value. Natomiast append zmienia samą listę, co widziałeś w B5.1. Funkcję obliczającą wynik wyłącznie z argumentów, bez zmieniania wejścia i otoczenia, nazywamy czystą. W naszym zadaniu oddziel liczenie od odczytu i zapisu pliku.

    Średnia znanych wartości

    Zgłoś brak danych do średniej

    Uzupełnij mean_known(values). Wejście to lista nieujemnych liczb i wartości None. Zwróć średnią znanych liczb jako float, uwzględniając zera. Dla pustej listy lub samych None zgłoś ValueError z tekstem no known values. Zachowaj wejście bez zmian. Sprawdzanie innych typów i liczb ujemnych nie należy do tego zadania.

    Podpowiedź 1

    Najpierw ustal, ile jest znanych wartości i jaka jest ich suma.

    Podpowiedź 2

    Przed dzieleniem sprawdź, czy istnieje mianownik różny od zera. Wynik oddaj po całej pętli.

    Sprawdź na własnym wejściu

    Bez zaglądania do kodu oblicz ręcznie wynik dla [None, 0, 8, 4], a potem wywołaj swoją funkcję. Własnymi słowami wyjaśnij, dlaczego [] nie powinno zwracać zera.

    Sprawdź uzasadnienie

    Wyjaśnij różnicę między wynikiem równym zero a brakiem danych do obliczenia wyniku. Zero może być średnią istniejących pomiarów. Dla pustej listy nie ma pomiarów, które można uśrednić. Porównaj też ręczny rachunek z wynikiem swojej funkcji.

    Powrót bez zaglądania

    Co kończy wykonanie funkcji? Jak przekazujesz obliczony wynik do innego fragmentu programu?

    Sprawdź własne wyjaśnienie

    return kończy wywołanie i zwraca wynik. print wyświetla informację na ekranie. Jeśli nadal mylisz te czynności, wróć do przykładu w A2.5 i sprawdź wartość zmiennej result.
