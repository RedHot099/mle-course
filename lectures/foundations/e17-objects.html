    Napisz klasę pamiętającą wynik fit

    Wrócisz do stanu estymatora. Tym razem samodzielnie określisz, jakie dane obiekt zapamiętuje między wywołaniami.

    Przed lekcją: D16.3 · Zbuduj etykietę jutra i model logistyczny.

    Znany obiekt, własna definicja

    DataFrame, scaler i model miały atrybuty oraz metody. Dotąd korzystaliśmy z gotowych klas. Teraz zdefiniujemy własną. Klasa opisuje sposób tworzenia obiektów; każda instancja może mieć osobny stan.

    Metoda __init__ ustawia początkowe atrybuty. Parametr self wskazuje konkretny obiekt. Przypisanie self.value zapisuje dane w nim, a zwykła zmienna lokalna znika po zakończeniu wywołania.

    class Counter:
    def __init__(self, start=0):
        self.value = start
    def add(self, amount):
        self.value += amount
        return self.value
first = Counter(2)
second = Counter(10)
print(first.add(3), second.value)

    Stan i kolejność

    Model średniej po fit pamięta średnią treningu. predict używa jej do nowej prognozy. Powinien zgłosić czytelny błąd, jeśli fit nie zostało wykonane. Dwie instancje muszą przechowywać własne dopasowania.

    Zacznij od zwykłej klasy. Nie potrzebujesz ABC, Protocol ani zaawansowanych generyków. Nie musisz też przechowywać w obiekcie całego zbioru, jeśli do predykcji wystarcza jedna liczba.

    Sprawdź samodzielnie

    Uzupełnij klasę LastValue. fit przyjmuje niepustą listę liczb bez None i zapisuje ostatnią wartość bez zmiany listy. predict zwraca ją. Przed fit zgłasza ValueError z komunikatem not fitted. Dla pustego fit zgłoś ValueError z komunikatem empty.
