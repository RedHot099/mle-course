    Policz małe attention

    Połączysz iloczyn skalarny, softmax i średnią ważoną. Sprawdzisz, dlaczego model potrzebuje kolejności pozycji i maski przyszłości.

    Przed lekcją: F20.7 · Od tekstu do celu modelu językowego, D13.5 · Policz iloczyn skalarny.

    Przewiduj wyniki przed uruchomieniem przykładów. Potem wykonaj kod i wyjaśnij różnice względem oczekiwania.

    Które elementy kontekstu wykorzystać

    Query jest wektorem pytania danej pozycji, key opisuje dopasowanie pozycji kontekstu, a value przenosi jej informację. Iloczyny query i keys dają wyniki podobieństwa. W typowym scaled dot-product attention dzielimy je przez pierwiastek wymiaru klucza.

    Softmax zamienia wyniki na dodatnie wagi o sumie 1: przekształca je funkcją exp i dzieli przez sumę. Dla stabilności najpierw odejmujemy maksimum. Wynik attention jest sumą wektorów value pomnożonych przez te wagi.

    import numpy as np
scores = np.array([0.,1.])
weights = np.exp(scores-scores.max())
weights = weights / weights.sum()
values = np.array([[2.,0.],[0.,4.]])
print(weights)
print(weights @ values)

    Pozycja i zakazana przyszłość

    Samo porównanie wektorów nie określa kolejności wyrazów. Model dostaje więc także informację o pozycjach. Przy przewidywaniu następnego tokenu maska causal blokuje dostęp do późniejszych tokenów; inaczej trening zawierałby odpowiedź.

    Wartość wyjściowa attention nie jest jeszcze rozkładem słów. Kolejne warstwy i końcowa projekcja dają wyniki dla słownika, a softmax prawdopodobieństwa. Attention jest mechanizmem przekształcania kontekstu, nie bazą prawdy i nie pełnym wyjaśnieniem odpowiedzi modelu.

    Sprawdź samodzielnie

    Dla wag [0.25,0.75] oraz wartości [4,0] i [0,8] oblicz średnią ważoną jako listę result. Zapisz, jakie wagi muszą otrzymać przyszłe pozycje po masce.

    Podpowiedź 1

    Mnożysz całe wektory przez ich wagi.

    Podpowiedź 2

    Wagi przyszłych pozycji po poprawnym maskowaniu wynoszą zero.

    Sprawdź, co pamiętasz

    Czy bardzo duża waga attention jest dowodem przyczynowej ważności tokenu dla odpowiedzi?

    Sprawdź własne wyjaśnienie

    Nie. Opisuje jeden etap obliczenia w modelu. Nie zastępuje eksperymentu i analizy całego przepływu.
