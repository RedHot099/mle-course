    Wytrenuj małą sieć z etykietami

    Uruchomisz pełną pętlę uczenia niewielkiej sieci na CPU i porównasz stratę treningu z oceną nowych punktów.

    Przykład wykonaj w notebooku na swoim komputerze. Ta lekcja nie wymaga GPU ani zewnętrznego API.

    Warstwy i parametry

    nn.Linear oblicza przekształcenie liniowe, a ReLU dodaje nieliniowość. nn.Module pomaga rejestrować warstwy i ich parametry. Własna klasa dziedziczy po Module; wywołanie super().__init__() przygotowuje stan potrzebny bibliotece. Metoda forward opisuje przepływ danych.

    Poniżej pokazujemy działający przykład na wymyślonych punktach. Nie jest to rozwiązanie ocenianego zadania Freshcast ani dowód generalizacji. Ustawiamy seed, małą sieć i CPU.

    import torch
from torch import nn
torch.set_num_threads(1)
torch.manual_seed(7)
class TinyNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.layers = nn.Sequential(nn.Linear(1,8), nn.ReLU(), nn.Linear(8,1))
    def forward(self,x):
        return self.layers(x)
X = torch.tensor([[-2.],[-1.],[0.],[1.],[2.]])
y = X.abs()
model = TinyNet()
optimiser = torch.optim.Adam(model.parameters(), lr=0.03)
loss_fn = nn.MSELoss()
initial = loss_fn(model(X),y).item()
for epoch in range(200):
    optimiser.zero_grad()
    loss = loss_fn(model(X),y)
    loss.backward()
    optimiser.step()
with torch.no_grad():
    final = loss_fn(model(X),y).item()
print(round(initial,4), round(final,4))
assert final < initial

    Sprawdź coś więcej niż spadek straty

    Zapisz loss co kilka epok i narysuj krzywą. Następnie zbuduj inne punkty do oceny, nieużywane przy aktualizacji wag. Porównaj je z prostym modelem liniowym. Jeden losowy seed i pięć punktów nie uzasadniają ogólnej przewagi architektury.

    Własna klasa sieci jest powodem, dla którego E17 poprzedza tę lekcję. Nie wymagamy wcześniej PCA ani wdrożenia pipeline, Dataset, GPU i Lightning.

    Sprawdź samodzielnie

    W notebooku przygotuj własny mały eksperyment z nieliniowym celem. Oddziel dane treningowe i walidacyjne przed próbami. Porównaj jedną sieć z modelem liniowym, pokaż krzywe i opisz, czego uczą się warstwy. Zmień tylko jeden element, na przykład liczbę jednostek, i powtórz porównanie.

    Sprawdź, co pamiętasz

    Czy hidden layer o większym rozmiarze zawsze poprawia walidację?

    Porównaj swoje wyjaśnienie

    Nie. Zwiększa rodzinę możliwych funkcji, ale może ułatwić dopasowanie przypadkowych szczegółów. Oceniaj nowe punkty i zapisz liczbę prób.
